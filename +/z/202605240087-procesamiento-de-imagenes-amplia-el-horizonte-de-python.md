## Idea

El ecosistema Python se extiende tambien al procesamiento de imagenes, lo que muestra la amplitud de dominios que pueden abordarse desde un lenguaje comun.

## Utilidad para el manual

Sirve para reforzar la idea de que aprender Python abre un repertorio muy amplio de aplicaciones.

## Parafrasis posible
