# El software libre reordena propiedad intelectual y libertades

- ID: 202605240185
- Fuente: Bain et al. (2007), Parte I
- Archivo fuente: [sf-parte-1.md](/Users/dante/github/manual-legaltech/+/y/libros-manuales/markdown/sf-parte-1.md)
- Capítulos potenciales: Tutoriales
- Temas: software-libre, propiedad-intelectual, licencias

## Idea

El software libre no niega la propiedad intelectual: la reorganiza mediante licencias que preservan libertades de uso, copia, modificacion y distribucion.

## Utilidad para el manual

Sirve para dar base conceptual al tutorial de licencias y reutilizacion responsable.

## Posibles inserciones

- tutorial de licencias;
- explicacion de diferencias entre software libre, abierto y propietario.

## Parafrasis posible

El software libre no funciona fuera del derecho de autor, sino apoyandose en licencias que usan ese marco para garantizar libertades especificas.
