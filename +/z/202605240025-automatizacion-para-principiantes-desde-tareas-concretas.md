## Idea

Una vía especialmente eficaz para enseñar programación a principiantes consiste en partir de tareas concretas y reconocibles, de modo que el sentido práctico del código aparezca desde el inicio.

## Utilidad para el manual

Respalda la lógica pedagógica del libro: enseñar Python no como un sistema abstracto cerrado, sino como una herramienta que resuelve problemas específicos y visibles.

## Posibles inserciones

- introducción de ejercicios prácticos en el capítulo 2;
- apertura del capítulo 4 antes de automatización documental.

## Paráfrasis posible

Para quienes empiezan, el aprendizaje del código se vuelve más claro cuando cada instrucción se vincula con una tarea concreta y reconocible, en lugar de presentarse como una técnica sin contexto.
