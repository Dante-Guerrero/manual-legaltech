## Idea

GitHub fue fundado en febrero de 2008, es decir, despues del nacimiento de Git, y su importancia radica en haber convertido un sistema distribuido en una plataforma visible de colaboracion y entrega.

## Utilidad para el manual

Ayuda a distinguir entre aprender Git y aprender a usar GitHub, dos cosas relacionadas pero no identicas.

## Posibles inserciones

- apertura del tutorial de Git y GitHub;
- aclaracion conceptual entre sistema y plataforma.

## Paráfrasis posible

GitHub no invento Git: aparecio despues y volvio mas facil compartir repositorios, colaborar y hacer visible el trabajo que Git ya podia versionar.
