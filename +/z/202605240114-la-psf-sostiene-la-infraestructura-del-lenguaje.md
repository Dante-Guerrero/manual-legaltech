## Idea

El crecimiento de Python depende tambien de una organizacion que sostiene infraestructura comun, no solo del lenguaje en abstracto.

## Utilidad para el manual

Sirve para mostrar que el ecosistema de Python tiene una base institucional concreta y que su estabilidad no es accidental.

## Parafrasis posible
