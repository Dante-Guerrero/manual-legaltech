## Idea

La historia oficial de VS Code presenta su origen como un intento de construir un editor basado en tecnologias web que no se sintiera como programar dentro del navegador.

## Utilidad para el manual

Sirve para abrir el tutorial de VS Code con una anecdota tecnica que explica por que el producto insiste tanto en velocidad, respuesta e integracion.

## Posibles inserciones

- apertura del tutorial de Visual Studio Code;
- parrafo sobre por que el editor resulta comodo para principiantes.

## Paráfrasis posible

VS Code nacio de una pregunta bastante concreta: si era posible construir un editor moderno con tecnologias web sin que la experiencia se sintiera lenta o artificial.
