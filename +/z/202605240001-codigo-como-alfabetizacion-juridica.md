# Código como alfabetización jurídica tecnológica

- Fuente: Contreras y McGrath (2020)
- Archivo fuente: [contreras-2020-law-technology-and-pedagogy.md](/Users/dante/github/manual-legaltech/+/y/papers_md/contreras-2020-law-technology-and-pedagogy.md)

- Temas: educacion-juridica, codigo, alfabetizacion-tecnologica

## Idea

Entender código tiene valor para juristas aunque no se aspire a formar expertos técnicos, porque una parte creciente del trabajo jurídico ya convive con datos, algoritmos y estructuras tecnológicas.

## Utilidad para el manual

Sirve para justificar por qué Python aparece en un manual para estudiantes de Derecho sin necesidad de presentar la programación como un fin en sí mismo.

## Posibles inserciones

- apertura del capítulo 2;
- transición del capítulo 3 desde sintaxis hacia trabajo con información.

## Paráfrasis posible

Aprender código en Derecho no implica convertirse en ingeniero, sino adquirir una alfabetización tecnológica suficiente para comprender un entorno profesional cada vez más mediado por datos, algoritmos y plataformas.
