# Código para problemas concretos y no abstractos

- ID: 202605240002
- Fuente: Contreras y McGrath (2020)

- Temas: pedagogia, contextualizacion, problemas-concretos

## Idea

La enseñanza de código en Derecho gana fuerza cuando se vincula con tareas reconocibles y no se queda en ejercicios abstractos desligados de la práctica.

## Utilidad para el manual

Sirve para sostener la lógica del capítulo 3, donde fechas, archivos y registros ya aparecen como problemas cercanos al trabajo jurídico real.

## Posibles inserciones

- `## ¿Por qué importa este tema?` del capítulo 3;
- `## Del fundamento al uso práctico` del capítulo 3.

## Paráfrasis posible

El aprendizaje se vuelve más significativo cuando la programación deja de aparecer como una sintaxis abstracta y empieza a vincularse con tareas reconocibles, como revisar fechas, organizar documentos o leer registros.
