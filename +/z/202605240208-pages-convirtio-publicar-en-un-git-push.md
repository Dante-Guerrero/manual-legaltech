## Idea

La formulacion original de GitHub Pages fue extremadamente simple y poderosa: publicar contenido web podia volverse tan facil como hacer `git push`.

## Utilidad para el manual

Sirve para abrir el tutorial de GitHub Pages con una anecdota historica que resume muy bien la relacion entre repositorio y sitio publicado.

## Posibles inserciones

- apertura del tutorial de GitHub Pages;
- cierre del tutorial como idea-fuerza.

## Paráfrasis posible

La gracia original de GitHub Pages no fue solo alojar sitios, sino volver casi indistinguibles el acto de versionar y el acto de publicar.
