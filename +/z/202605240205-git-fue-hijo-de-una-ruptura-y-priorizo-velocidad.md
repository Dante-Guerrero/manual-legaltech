## Idea

Git surgio en 2005 tras la ruptura entre la comunidad del kernel de Linux y BitKeeper, y fue disenado desde el comienzo para ser rapido, distribuido y apto para proyectos enormes.

## Utilidad para el manual

Sirve para evitar que Git se presente como una simple lista de comandos sin contexto. Su origen explica por que el historial y la distribucion son tan centrales.

## Posibles inserciones

- apertura del tutorial de Git y GitHub;
- explicacion de por que Git sirve incluso para proyectos pequenos del curso.

## Paráfrasis posible

Git no aparecio como comodidad administrativa, sino como respuesta a un problema real de colaboracion a gran escala, y por eso su diseno prioriza velocidad, historial y trabajo distribuido.
