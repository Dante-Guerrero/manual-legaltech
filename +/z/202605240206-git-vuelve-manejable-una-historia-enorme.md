## Idea

La pagina oficial de Git usa un dato muy expresivo para explicar su eficiencia: la historia completa del proyecto Linux, con 1.4 millones de commits, cabe en 5.5 GB.

## Utilidad para el manual

Sirve para convertir una propiedad tecnica abstracta en una imagen concreta y memorable para estudiantes.

## Paráfrasis posible

Si Git puede conservar de manera eficiente una historia gigantesca como la del kernel de Linux, tambien puede tratar con solvencia el historial mucho mas modesto de un proyecto academico.
