# Git convierte cambios en historial trazable

- ID: 202605240139
- Fuente: Chacon y Straub (2014)

- Temas: git, versionado, trazabilidad

## Idea

Git convierte modificaciones dispersas en un historial estructurado de cambios, lo que vuelve el trabajo mas trazable, reversible y colaborativo.

## Utilidad para el manual

Sirve para justificar por que Git y GitHub no son un obstaculo administrativo del curso, sino parte de su infraestructura formativa.

## Posibles inserciones

- tutorial de Git y GitHub;
- explicacion del valor de los commits en evaluaciones practicas.

## Parafrasis posible

Versionar no significa solo guardar copias: significa construir un historial verificable de decisiones y cambios sobre un proyecto.
