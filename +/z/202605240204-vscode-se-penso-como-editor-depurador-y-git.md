## Idea

La historia oficial de VS Code destaca que desde temprano el proyecto no quiso ser solo editor, sino una herramienta para navegar codigo, depurar y trabajar con Git dentro del mismo entorno.

## Utilidad para el manual

Ayuda a justificar por que el curso usa VS Code como espacio principal de trabajo y no solo como bloc de notas avanzado.

## Posibles inserciones

- seccion inicial del tutorial de Visual Studio Code;
- transicion hacia terminal integrada y control de cambios.

## Paráfrasis posible

VS Code fue pensado desde el inicio como un entorno donde escribir, probar y versionar convivieran en una sola interfaz.
