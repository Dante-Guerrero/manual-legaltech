## Idea

HTML cumple una funcion estructural: organiza el contenido que el navegador mostrara, antes de cualquier decision de estilo.

## Utilidad para el manual

Permite explicar la web desde capas distintas y evita que la pagina se entienda solo como un objeto visual.

## Posibles inserciones

- seccion de estructura minima de una pagina;
- comparacion entre HTML y CSS.

## Paráfrasis posible

Antes de pensar en colores o tipografias, una pagina web necesita una estructura: titulos, parrafos, enlaces y archivos que el navegador pueda interpretar.
