# `+/x`: capa operativa

La carpeta `+/x` reúne la memoria operativa del proyecto. Aquí no vive el contenido final del manual, sino los documentos y herramientas que ayudan a producirlo, corregirlo y mantenerlo.

## Qué contiene

- [editorial](/Users/dante/github/manual-legaltech/+/x/editorial): criterios relativamente estables de estilo, formulación y planificación.
- [instrucciones](/Users/dante/github/manual-legaltech/+/x/instrucciones): procedimientos de trabajo, notas de conversión y guías de aplicación.
- [scripts](/Users/dante/github/manual-legaltech/+/x/scripts): utilitarios y materiales de ejercicios usados como apoyo pedagógico o técnico.
