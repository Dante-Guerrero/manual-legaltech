## Resumen util

La pagina oficial de prensa de GitHub ofrece un dato historico breve pero muy util: GitHub fue fundado en febrero de 2008. Aunque parezca un detalle menor, esa fecha ayuda a situar a GitHub no como una extension natural de Git desde siempre, sino como una plataforma posterior que transformo la colaboracion en torno a repositorios distribuidos.

Ademas, la pagina actualiza la escala de la plataforma con cifras agregadas que ayudan a mostrar por que GitHub termino volviendose una infraestructura de trabajo comun para proyectos pequenos, cursos y comunidades globales.

## Datos puntuales aprovechables
