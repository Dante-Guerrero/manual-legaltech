## Resumen util

El tutorial oficial de Python presenta al lenguaje como facil de aprender, potente y adecuado para scripting y desarrollo rapido, con estructuras de datos de alto nivel y una sintaxis elegante. Esa descripcion encaja muy bien con el capitulo 2, que no busca formar especialistas en software sino mostrar por que Python es una buena puerta de entrada para estudiantes de Derecho.

Ademas, la propia tabla de contenidos del tutorial oficial coincide con varios ejes del capitulo: numeros, texto, listas, control de flujo, funciones, estructuras de datos y lectura/escritura de archivos. Esto permite respaldar pedagogicamente la secuencia del manual con la misma arquitectura de aprendizaje que usa la documentacion oficial.
