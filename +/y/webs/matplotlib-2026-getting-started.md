## Resumen util

La guia de inicio de Matplotlib presenta un camino muy directo desde instalacion hasta un primer grafico. Para el capitulo 4, esto es util porque muestra que producir visualizaciones no requiere abandonar Python ni pasar a otra herramienta completamente distinta.

La pagina tambien deja claro que un grafico nace de objetos como figura y ejes, no solo de "dibujar barras". Pedagogicamente, eso ayuda a sostener que la visualizacion juridica tambien es una forma de salida estructurada a partir de datos.

## Datos puntuales aprovechables

- Matplotlib puede instalarse directamente con `pip install matplotlib`.
- La guia oficial propone un ejemplo minimo de primer grafico con `pyplot`.
- La documentacion orienta al usuario hacia tipos de graficos y una guia de inicio mas profunda.
- La biblioteca se presenta como una herramienta para crear visualizaciones desde Python.
