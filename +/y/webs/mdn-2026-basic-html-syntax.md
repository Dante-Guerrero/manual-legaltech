## Resumen util

La guia de MDN sobre sintaxis basica de HTML define HTML como el lenguaje de marcado que indica al navegador como estructurar una pagina web. Esa formulacion es ideal para el capitulo 7 porque permite distinguir con claridad la capa estructural de la capa visual.

Tambien es muy util que MDN recuerde que HTML vive en archivos de texto con extension `.html` y que `index.html` suele contener la pagina de inicio. Eso hace mas concreta la idea de que una pagina web estatica no es una abstraccion: es un conjunto manejable de archivos.

## Datos puntuales aprovechables

- HTML estructura el contenido que renderiza el navegador.
- Los elementos y etiquetas marcan funciones distintas del contenido.
- Los archivos HTML suelen tener extension `.html`.
- `index.html` aparece como archivo tipico para una pagina principal.

## Posibles usos en el manual

- reforzar la distincion entre internet, web y archivo web concreto;
- apoyar la explicacion minima de titulos, parrafos y enlaces;
- justificar por que una pagina estatica puede construirse con archivos simples.
