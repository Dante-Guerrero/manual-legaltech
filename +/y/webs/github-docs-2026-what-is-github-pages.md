## Resumen util

La documentacion oficial de GitHub define GitHub Pages como un servicio de alojamiento de sitios estaticos que toma archivos HTML, CSS y JavaScript directamente desde un repositorio, con la opcion de pasar por un proceso de build antes de publicar. Es una formulacion muy precisa para el capitulo 7, porque une publicacion web, repositorio y trazabilidad.

Tambien distingue entre sitios de usuario u organizacion y sitios de proyecto. Esa diferencia sirve para mostrar que publicar no exige infraestructura compleja: en muchos casos basta con tener el sitio versionado y estructurado dentro del propio flujo de GitHub.

## Datos puntuales aprovechables

- GitHub Pages aloja sitios estaticos.
- Publica directamente desde archivos del repositorio.
- Puede usar un proceso de compilacion antes de publicar.
- Distingue entre sitios de usuario/organizacion y sitios de proyecto.
