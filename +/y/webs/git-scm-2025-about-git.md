## Resumen util

La pagina oficial "About Git" aporta dos ideas especialmente claras para el manual. La primera es historica: Git fue construido para trabajar con el kernel de Linux, de modo que velocidad y rendimiento no fueron mejoras agregadas despues, sino objetivos de diseno desde el inicio. La segunda es casi anecdotica y muy pedagogica: el sitio destaca que Git guarda la historia completa del proyecto Linux, con 1.4 millones de commits, en apenas 5.5 GB.

Esto sirve para presentar Git como algo mas que una lista de comandos. Su razon de ser esta ligada al manejo eficiente de proyectos complejos y a la conservacion de historia verificable a gran escala.

## Datos puntuales aprovechables

- Git fue construido para trabajar sobre el kernel de Linux.
- La velocidad fue un objetivo de diseno desde el comienzo.
- En 2025, Git almacenaba la historia completa del proyecto Linux, con 1.4 millones de commits, en 5.5 GB.
- La pagina oficial remarca que muchas interfaces graficas e integraciones de editor nacieron alrededor del nucleo de Git.

## Posibles usos en el manual

- dar una entrada historica y tecnica al tutorial de Git;
- explicar por que el historial no es "peso muerto" sino infraestructura;
- reforzar la idea de que Git puede usarse en proyectos mucho mas grandes que los del curso sin perder sentido.
