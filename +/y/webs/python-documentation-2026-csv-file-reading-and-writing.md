## Resumen util

La documentacion oficial del modulo `csv` presenta a CSV como un formato tabular que Python puede leer y escribir sin obligar al usuario a conocer todos los detalles internos de cada variante. Eso es util para el capitulo 6 porque conecta el trabajo juridico con una forma simple y muy difundida de estructurar registros.

Tambien resulta valioso que la documentacion distinga entre lectura y escritura secuencial y trabajo en forma de diccionario mediante `DictReader` y `DictWriter`. Para estudiantes de derecho, esa distincion ayuda a pasar de una tabla "vista en filas" a una tabla pensada como campos reutilizables.

## Datos puntuales aprovechables

- El modulo `csv` implementa clases para leer y escribir datos tabulares en formato CSV.
- Python ofrece objetos `reader` y `writer` para secuencias.
- Python ofrece `DictReader` y `DictWriter` para trabajar con filas como pares campo-valor.
- La propia documentacion presenta CSV como un puente practico entre Python y formatos comunes en hojas de calculo.
