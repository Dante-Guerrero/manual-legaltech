## Resumen util

La entrada oficial de lanzamiento de VS Code 1.0 cuenta una historia especialmente util para el manual: el proyecto empezo como un intento de construir un editor rapido con tecnologias web sin que se sintiera como "programar dentro del navegador". La nota explica que el primer preview publico aparecio en `//build/ 2015`, que seis meses despues el proyecto ya tenia extensibilidad y marketplace, y que en noviembre de 2015 el repositorio y muchas extensiones pasaron a desarrollarse en abierto.

Tambien resulta valioso que la propia historia del producto conecte desde el inicio varias funciones que en el curso importan mucho: editar, depurar y trabajar con Git en un mismo entorno. Eso ayuda a presentar VS Code no solo como editor de texto, sino como un espacio de trabajo unificado.

## Datos puntuales aprovechables

- El equipo se pregunto si podia construir un editor "tan rapido que no se sintiera como escribir en un navegador".
- El primer preview publico de VS Code se presento en `//build/ 2015`.
- Seis meses despues ya existian extensibilidad y Visual Studio Marketplace.
- El desarrollo se abrio al publico en noviembre de 2015.
- La historia oficial destaca desde temprano edicion, depuracion y trabajo con Git como nucleo del producto.

## Posibles usos en el manual

- abrir el tutorial de Visual Studio Code con una anecdota de origen;

- reforzar la idea de que Git ya viene integrado en el flujo de trabajo del editor.
