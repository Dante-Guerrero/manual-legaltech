# Webs

Esta carpeta guarda extractos manuales en Markdown de paginas web que ya son citadas en el manual o que podrian citarse despues.

## Regla basica

Aqui no se guardan enlaces sueltos ni marcadores. Cada archivo debe contener:

- la clave bibliografica asociada;
- la URL;
- la fecha de consulta usada en la bibliografia;
- un resumen util para el manual;
- datos puntuales reutilizables;
- posibles usos editoriales.

## Cuándo usar esta carpeta

Usa `+/y/webs` cuando la fuente:

- sea documentacion oficial en linea;
- no entre naturalmente en `papers`, `normas`, `libros-manuales` o `jurisprudencia`;
- ya aparezca citada en el manual o tenga alta probabilidad de ser citada.

## Relacion con `+/z`

Si un extracto web contiene una idea reutilizable, conviene derivar una o mas notas atomicas en `+/z` para no volver a reconstruir esa fuente desde cero.
