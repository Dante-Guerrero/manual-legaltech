## Resumen util

La FAQ oficial presenta a Python como un lenguaje interpretado, interactivo, orientado a objetos pero no limitado a ese paradigma. Tambien destaca su sintaxis clara, su extensibilidad en C o C++ y su portabilidad entre Linux, macOS y Windows.

La misma FAQ explica dos piezas historicas especialmente utiles para el manual. Primero, que Python nacio de necesidades practicas vinculadas a la administracion de sistemas y a los limites de ABC. Segundo, que su nombre fue escogido por Guido van Rossum a partir de Monty Python porque buscaba una denominacion corta, distintiva y algo misteriosa.

## Datos puntuales aprovechables

- Python admite enfoques procedimentales, funcionales y orientados a objetos.
- La claridad sintactica aparece como rasgo oficial del lenguaje.
- El lenguaje fue pensado para ser extensible y util en problemas reales.
- La eleccion del nombre forma parte de la identidad cultural del proyecto.
