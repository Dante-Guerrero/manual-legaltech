## Resumen util

La documentacion oficial de GitHub presenta 2FA como una capa adicional de seguridad y explica que, para acceder a una cuenta, no basta con la contraseña: tambien hace falta un segundo factor. En un curso donde GitHub es parte del trabajo ordinario, esta fuente tiene valor doble: seguridad general y practica concreta del ecosistema usado por el alumnado.

La pagina ademas subraya dos puntos utiles para el manual: GitHub ha empujado activamente la adopcion de 2FA entre contribuidores y la configuracion responsable incluye metodos de recuperacion. Eso ayuda a mostrar que seguridad no es solo activar una opcion, sino preparar continuidad de acceso.

## Datos puntuales aprovechables

- GitHub define 2FA como una capa extra de seguridad para el inicio de sesion.
- El segundo factor puede provenir de una app TOTP, SMS, llave de seguridad o mecanismos equivalentes.
- GitHub impulsó 2FA para usuarios que contribuyen codigo en la plataforma.
- Los codigos o metodos de recuperacion son parte critica de la configuracion.

## Posibles usos en el manual

- reforzar que una buena higiene de seguridad incluye autenticacion robusta;
- conectar la teoria del capitulo con una practica inmediata del curso;
- apoyar una recomendacion concreta sobre cuentas de repositorio y materiales sensibles.
