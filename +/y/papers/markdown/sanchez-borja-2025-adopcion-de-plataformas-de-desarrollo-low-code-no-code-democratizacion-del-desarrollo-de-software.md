Palabras clave: investigación, plataforma, aplicación, codificación, programación Abstract This research explored the use of low-code/no-code development platforms as a promising option for building applications. This is especially relevant given the complexity of traditional methodologies. Low-code platforms are aimed at users with some level of technical knowledge, as they allow users to develop with minimal coding through the use of visual interfaces. In contrast, no-code platforms completely eliminate the need for programming. These platforms are more suitable for non-technical business users or organizations. The emphasis of this research is that no- code platforms shift the application development paradigm for most users. Furthermore, they lower barriers to entry and accelerate value creation processes. Other advantages include reduced development time and costs, along with greater flexibility. However, these platforms also have some disadvantages. Some limitations include the lack of suitable custom solutions and vendor lock-in, particularly for no-code solutions. Low-code/no-code El impulso de software con enfoque code/no-code es una tendencia en crecimiento que permite la creación de aplicaciones con un mínimo de programación manual, facilitando la inclusión de personas sin experiencia en codificación en el proceso de desarrollo, este método ayuda a las empresas a reducir tiempos y costos gracias a una mayor rapidez en la producción de software [8]. 3.2. Low-code El low-code es un método de perfeccionamiento de software que reduce la necesidad de programación manual al permitir la creación de aplicaciones mediante interfaces gráficas, modelos visuales y componentes pre configurados. Su propósito principal es simplificar el desarrollo de software para personas sin experiencia avanzada en programación, conocidos como Citizen Developers [9]. 3.2.1. Características: Automatización: Disminución del tiempo de codificación manual gracias a la reutilización de módulos y componentes predefinidos y la incorporación de inteligencia artificial y técnicas como Model-Based Testing (MBT) para generar pruebas automáticas [9]. Pruebas y aseguramiento de calidad: La validación de software en entornos low-code requiere nuevas estrategias que hagan posible la intervención de los beneficiarios sin conocimientos técnicos y existen retos en la automatización de pruebas y en la generación de casos de prueba sin necesidad de programar [10]. 3.3. No-code No-code es una evolución dentro del desarrollo de software que hace posible la elaboración de aplicaciones sin necesidad de escribir código y su objetivo principal es propiciar que usuarios sin instrucciones técnicas desarrollen soluciones digitales a través de interfaces visuales intuitivas [3]. 3.3.1.
