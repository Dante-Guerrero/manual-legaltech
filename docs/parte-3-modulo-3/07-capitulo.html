7. El internet y la nube

NoteQué aprenderás en esta sesión

Esta sesión introduce una capa de infraestructura que suele permanecer invisible cuando solo usamos plataformas y páginas ya hechas. El objetivo es distinguir internet, web, dominio, servidor, hosting y nube; entender la estructura mínima de una página; y advertir por qué publicar información digital también implica exposición, mantenimiento y criterio profesional.

La web también es infraestructura jurídica

Muchos servicios jurídicos actuales se prestan, difunden o documentan a través de la web. Portales institucionales, formularios de atención, publicaciones regulatorias, sitios profesionales y sistemas de consulta conviven hoy con el trabajo legal cotidiano. Entender esa infraestructura no convierte a un jurista en ingeniero, pero sí le permite leer con más precisión el entorno donde circulan documentos, reputación y servicios.

Internet, web y nube no son lo mismo

En conversación cotidiana solemos mezclar estos términos como si fueran equivalentes, pero no lo son. Internet es la red general de comunicación; la web es uno de los servicios que funciona sobre esa red; el navegador es la herramienta de acceso; el servidor aloja el contenido; el dominio lo vuelve localizable; y el hosting o la nube hacen posible que ese contenido permanezca disponible desde infraestructura remota. Separar estas ideas importa porque publicar no es un acto abstracto: implica soporte técnico, acceso, exposición y dependencia de servicios concretos.

Publicar también es asumir exposición

Para una facultad de Derecho, este tema importa por dos razones. La primera es profesional: una parte creciente de la actividad jurídica se presenta, organiza o consulta desde entornos web. La segunda es formativa: entender cómo se publica algo ayuda a pensar mejor disponibilidad, reputación, control y seguridad de la información. Una página sencilla puede ser una pieza menor en términos técnicos y, al mismo tiempo, una pieza muy relevante en términos públicos.

ImportantAntes de empezar

Para esta sesión basta con una carpeta de trabajo simple, un archivo index.html y, si quieres separar estilos, un archivo style.css. La meta no es construir un sitio complejo, sino entender la relación entre estructura, apariencia y publicación. Si más adelante decides usar GitHub Pages, ese paso tendrá más sentido si primero comprendes qué estás publicando y cómo está organizado.

Estructura mínima de una página web

Una página simple suele combinar tres capas:

  • HTML: estructura del contenido;
  • CSS: apariencia y estilo;
  • JavaScript: comportamiento o interacción cuando hace falta.

HTML dice qué cosa es cada parte: un título, un párrafo, una lista o un enlace. CSS define cómo se ve: colores, márgenes, tipografía y disposición. JavaScript permite comportamiento dinámico, aunque en una sesión introductoria puede mantenerse al mínimo.

Un ejemplo muy básico con HTML

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Perfil Legal Tech</title>
  </head>
  <body>
    <h1>Ana Perez</h1>
    <p>Estudiante de Derecho interesada en tecnologia y regulacion.</p>
    <a href="https://github.com/">Mi GitHub</a>
  </body>
</html>

Este archivo ya es, en sentido estricto, una página web muy simple.

Qué hace CSS en este contexto

Si agregamos CSS, la página puede verse más legible y ordenada:

body {
  font-family: Georgia, serif;
  max-width: 720px;
  margin: 2rem auto;
  line-height: 1.6;
}

h1 {
  color: #1f3c88;
}

No hace falta buscar complejidad visual de inmediato. Una página sobria, clara y profesional suele ser mucho más útil para el curso.

Páginas estáticas y dinámicas

También conviene distinguir dos ideas:

  • página estática: su contenido se sirve tal como fue escrito en archivos;
  • página dinámica: su contenido puede construirse o cambiar en tiempo real según base de datos, usuario u otras condiciones.

Para este curso, una página estática es ideal como punto de partida porque obliga a entender estructura, es fácil de publicar y permite concentrarse en fundamentos sin complejidad innecesaria.

La nube, en términos simples

Cuando hablamos de nube, muchas veces nos referimos a servicios que corren en infraestructura remota accesible por internet. No es magia: son servidores, almacenamiento y aplicaciones que no viven necesariamente en tu computadora personal. Desde una mirada pedagógica, basta con advertir tres cosas:

  • publicar un sitio suele implicar usar infraestructura ajena;
  • guardar archivos en plataformas también implica confiar en servicios remotos;
  • trabajar en la nube supone pensar en acceso, disponibilidad y seguridad.
TipCriterio útil

Una buena página para este curso no necesita ser compleja. Necesita ser clara, legible, propia y públicamente accesible cuando decidas publicarla.

GitHub Pages como herramienta pedagógica

GitHub Pages resulta especialmente útil porque conecta varias dimensiones a la vez:

  • repositorio;
  • control de versiones;
  • publicación;
  • evidencia de trabajo.

Eso lo vuelve adecuado para el curso, ya que el producto final no queda separado del proceso que lo produjo. El mismo entorno donde editas y versionas puede servir también para publicar.

Qué se gana al publicar algo propio

Publicar una página simple deja ver varias competencias al mismo tiempo:

  • organización de contenido;
  • escritura con propósito;
  • estructura básica de HTML;
  • comprensión elemental de infraestructura web.

No se trata de formar diseñadores web en una sesión. Se trata de que el estudiante entienda cómo funciona una publicación digital básica y la use con sentido profesional.

Práctica en editor

Crea una página mínima con:

  • un título;
  • una breve presentación;
  • una sección sobre intereses o experiencia;
  • un enlace;
  • un archivo HTML y, si es posible, un archivo CSS separado.

Conclusiones del capítulo

Entender la web desde dentro cambia la relación con las plataformas que usamos todos los días. Lo que antes parecía un espacio abstracto empieza a verse como una combinación concreta de estructura, infraestructura y decisiones de publicación. Para una formación jurídica, esa mirada importa porque aclara dónde circula la información y bajo qué condiciones se vuelve visible.

TipIdeas clave
  • internet, web y nube no son sinónimos;
  • una página web combina estructura, estilo y, cuando hace falta, comportamiento;
  • publicar información digital también implica exposición e infraestructura;
  • una página estática es un buen punto de entrada para aprender a publicar con criterio.
CautionPara pensar y reflexionar

Buena parte del trabajo jurídico contemporáneo ocurre en entornos que alguien diseñó, alojó y puso en línea. Entender esa materialidad técnica ayuda no solo a publicar mejor, sino también a evaluar con más criterio qué significa confiar información, identidad profesional o servicios a una plataforma.
