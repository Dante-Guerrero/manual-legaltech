3. Python para fechas, archivos y datos

NoteQué aprenderás en esta sesión

Este capítulo marca un cambio importante en el recorrido. Python deja de aparecer solo como un lenguaje para aprender sintaxis y empieza a mostrar su utilidad en tareas próximas al trabajo con información jurídica. A través de fechas, plazos simples, archivos de texto, registros en CSV y tablas con pandas, el objetivo es ver cómo un programa puede organizar, revisar y resumir datos de una manera más controlada.

¿Por qué importa este tema?

En la práctica jurídica, muchos problemas no se resuelven solo con definiciones abstractas. Hace falta revisar fechas, calcular días entre actos procesales, leer documentos, registrar observaciones, ordenar expedientes y mirar tablas con datos. Todo eso forma parte del trabajo real y, precisamente por eso, es un buen terreno para seguir aprendiendo Python. La programación gana poder pedagógico justamente cuando deja de sentirse como sintaxis aislada y empieza a vincularse con tareas reconocibles de la práctica (Contreras and McGrath 2020).

En la sesión anterior aparecieron variables, tipos de datos, condicionales, bucles, funciones, listas y texto. Ahora esas bases se desplazan hacia contextos más concretos. Manejar fechas, archivos y tablas con cierta soltura ya supone entrar en una forma de trabajo más próxima a la automatización básica y al análisis ordenado de información.

Del fundamento al uso práctico

El paso que da este capítulo es muy natural. Primero aprendiste a escribir instrucciones simples y a entender qué hace cada línea. Ahora vas a usar esa misma lógica para responder preguntas como estas:

  • ¿qué fecha tiene hoy el sistema?;
  • ¿cuántos días han pasado entre una presentación y una audiencia?;
  • ¿cuándo vence un plazo si se suman ciertos días?;
  • ¿cómo se lee un documento desde un archivo?;
  • ¿cómo se guarda una nota generada por el programa?;
  • ¿cómo se leen registros de un CSV?;
  • ¿cómo se filtran o resumen datos en una tabla?

Es decir, el capítulo empieza a mostrar que programar no solo sirve para aprender sintaxis. También sirve para trabajar con información de una manera más precisa y trazable.

Fechas, archivos y datos en clave jurídica

Estos tres temas tienen una relación muy directa con el trabajo legal. Las fechas importan porque muchos procedimientos dependen de plazos y secuencias temporales. Los archivos importan porque una parte enorme del trabajo profesional consiste en leer, guardar y mover documentos. Y los datos importan porque expedientes, multas, registros, estados y categorías suelen terminar organizados en tablas que necesitan revisarse y resumirse.

Lo importante aquí no es imaginar que Python reemplaza el criterio jurídico. Lo importante es ver que puede ayudar a hacer visible y repetible la parte estructurada del trabajo: calcular, leer, ordenar, filtrar y resumir.

Ejercicios prácticos para trabajar con fechas, archivos y datos

La secuencia del capítulo no es arbitraria. Primero aparecen las fechas, porque introducen objetos nuevos pero cercanos a problemas muy reconocibles. Luego vienen los archivos, donde el programa ya se vincula con documentos reales. Finalmente, la sección de datos permite ver cómo Python y pandas ayudan a leer tablas y a extraer de ellas información relevante.

La mejor manera de trabajar esta parte sigue siendo práctica: ejecutar cada ejercicio, revisar la salida, cambiar uno o dos valores y volver a correr el script. Esas variaciones pequeñas permiten entender con precisión de qué depende el resultado.

Fechas: empezar a pensar el tiempo con Python

Trabajar con fechas es una habilidad especialmente útil en contextos jurídicos. Muchos trámites, audiencias, notificaciones y vencimientos dependen de contar días o ubicar un acto en el tiempo. Por eso, esta sección sirve como un primer puente entre Python y tareas que ya se parecen más a la práctica real.

Ejercicio 1. Mirar el reloj del sistema: obtener la fecha actual

El punto de partida más simple es pedirle a Python la fecha de hoy. Este ejercicio es pequeño, pero enseña una idea importante: las fechas no se manejan solo como texto, sino como objetos que luego permiten extraer partes concretas como el año, el mes o el día.

Crea un archivo nuevo y copia este código:

from datetime import date

hoy = date.today()

print("Fecha de hoy:", hoy)
print("Año:", hoy.year)
print("Mes:", hoy.month)
print("Dia:", hoy.day)

Qué hace este código

El programa importa una herramienta de Python para trabajar con fechas, obtiene la fecha actual del sistema y luego muestra esa fecha completa y también sus partes por separado.

Qué hace cada parte

  • from datetime import date importa la clase date desde el módulo datetime.
  • date representa una fecha sin hora: año, mes y día.
  • date.today() consulta la fecha actual del sistema donde se está ejecutando el programa.
  • hoy.year, hoy.month y hoy.day acceden a atributos del objeto fecha.
  • Se usan esos atributos porque muchas veces no basta con ver la fecha completa: también interesa extraer partes concretas para compararlas o mostrarlas de otra forma.

Qué verás en la terminal

Si el programa se ejecutara, por ejemplo, el 24 de mayo de 2026, verías algo parecido a esto:

Fecha de hoy: 2026-05-24
Año: 2026
Mes: 5
Dia: 24

Ese resultado aparece porque date.today() devuelve un objeto fecha y print() muestra tanto el objeto completo como cada atributo por separado. Conviene añadir líneas como print("Dia de hoy en texto:", hoy.day) o crear otra fecha manual con date(2026, 12, 31) para compararla con la actual. Así se entiende mejor que una fecha no es solo un texto visible, sino una estructura con partes que pueden aislarse y reutilizarse.

Ejercicio 2. Contar días entre dos actuaciones

Una tarea muy común en el trabajo jurídico consiste en medir el tiempo entre dos eventos: presentación y audiencia, notificación y respuesta, inicio y vencimiento. Este ejercicio muestra cómo convertir texto en fechas reales y luego restarlas para obtener una diferencia de días.

Crea un archivo nuevo y copia este código:

from datetime import datetime

fecha_presentacion = datetime.strptime("2026-03-01", "%Y-%m-%d")
fecha_audiencia = datetime.strptime("2026-03-18", "%Y-%m-%d")

diferencia = fecha_audiencia - fecha_presentacion

print("Fecha de presentacion:", fecha_presentacion.date())
print("Fecha de audiencia:", fecha_audiencia.date())
print("Dias entre ambas fechas:", diferencia.days)

Qué hace este código

El programa toma dos fechas escritas como texto, las convierte en objetos de fecha y hora, las resta y luego muestra cuántos días hay entre ambas.

Qué hace cada parte

  • from datetime import datetime importa la clase datetime, que permite representar fecha y hora.
  • datetime.strptime(...) convierte una cadena de texto en un objeto fecha usando un formato específico.
  • "%Y-%m-%d" le dice a Python que espere año con cuatro dígitos, luego mes y luego día.
  • fecha_audiencia - fecha_presentacion produce una diferencia de tiempo.
  • diferencia.days extrae el número de días de esa diferencia.
  • fecha_presentacion.date() y fecha_audiencia.date() muestran solo la parte de fecha, sin la hora.

Qué verás en la terminal

Fecha de presentacion: 2026-03-01
Fecha de audiencia: 2026-03-18
Dias entre ambas fechas: 17

El resultado 17 aparece porque Python interpreta ambas fechas como objetos comparables y luego calcula la distancia temporal entre ellas. Si cambias una de las fechas, diferencia.days varía de inmediato. También es útil invertir el orden de la resta: el resultado puede volverse negativo, y eso deja ver que en los cálculos temporales el orden de los actos sí importa.

Ejercicio 3. Sumar días para calcular un vencimiento

Si el ejercicio anterior servía para medir la distancia entre dos fechas, este sirve para proyectar una fecha futura. Es un tipo de cálculo muy útil cuando se quiere obtener un vencimiento simple a partir de una notificación o una actuación inicial.

Crea un archivo nuevo y copia este código:

from datetime import datetime, timedelta

fecha_notificacion = datetime.strptime("2026-03-06", "%Y-%m-%d")

plazo = timedelta(days=5)
fecha_vencimiento = fecha_notificacion + plazo

print("Fecha de notificacion:", fecha_notificacion.date())
print("Plazo en dias:", plazo.days)
print("Fecha de vencimiento:", fecha_vencimiento.date())

Qué hace este código

El programa convierte una fecha escrita como texto en un objeto fecha, construye un plazo de cinco días y luego lo suma para obtener una fecha de vencimiento.

Qué hace cada parte

  • timedelta(days=5) crea una duración de cinco días.
  • timedelta no representa una fecha, sino una cantidad de tiempo.
  • fecha_notificacion + plazo suma esa duración a la fecha inicial.
  • plazo.days muestra el número de días contenidos en el objeto plazo.
  • Se usa esta lógica porque, en muchos contextos, el problema no es comparar dos fechas ya dadas, sino calcular una nueva fecha a partir de una regla temporal.

Qué verás en la terminal

Fecha de notificacion: 2026-03-06
Plazo en dias: 5
Fecha de vencimiento: 2026-03-11

La fecha final aparece porque Python suma cinco días corridos a la fecha de notificación y devuelve un nuevo objeto fecha. Cambiar days=5 por days=10 o usar otra fecha inicial permite ver cómo se modifica el vencimiento. También resulta instructivo probar con una fecha cercana al final de un mes: Python gestiona automáticamente el cambio de mes sin necesidad de hacerlo a mano.

Archivos: hacer que el programa lea y escriba documentos

Después de trabajar con fechas, el paso natural es permitir que el programa se conecte con archivos reales. Esto importa mucho porque gran parte del trabajo profesional ocurre sobre documentos: leer un texto, guardar una nota, revisar un CSV o recuperar registros almacenados.

Ejercicio 4. Leer un archivo de texto

Un programa se vuelve más útil cuando no depende solo de información escrita dentro del propio código. Este ejercicio muestra cómo abrir un archivo .txt, leer su contenido completo y mostrarlo en pantalla.

Antes de ejecutar el script, crea un archivo llamado edicto.txt dentro de tu carpeta data con este contenido:

Edicto de ejemplo

Se comunica que la audiencia del expediente EXP-001 ha sido programada para el 18 de marzo de 2026.

Luego crea un archivo nuevo y copia este código:

from pathlib import Path

ruta_archivo = Path(__file__).parent / "data" / "edicto.txt"

with open(ruta_archivo, "r", encoding="utf-8") as archivo:
    contenido = archivo.read()

print("Contenido del archivo:")
print(contenido)

Qué hace este código

El programa construye la ruta del archivo de texto, lo abre en modo lectura, guarda todo su contenido en una variable y luego lo imprime en la terminal.

Qué hace cada parte

  • from pathlib import Path importa una herramienta moderna para trabajar con rutas de archivos.
  • Path(__file__).parent se refiere a la carpeta donde está guardado el script.
  • / "data" / "edicto.txt" completa la ruta hacia el archivo que se quiere leer.
  • open(ruta_archivo, "r", encoding="utf-8") abre el archivo en modo lectura.
  • encoding="utf-8" ayuda a leer bien acentos y caracteres propios del español.
  • archivo.read() toma todo el contenido del archivo como un solo bloque de texto.
  • with ... as archivo: asegura que el archivo se cierre correctamente cuando termina la lectura.

Qué verás en la terminal

Contenido del archivo:
Edicto de ejemplo

Se comunica que la audiencia del expediente EXP-001 ha sido programada para el 18 de marzo de 2026.

Esa salida aparece porque archivo.read() recupera todo el contenido del documento tal como está guardado y print() lo muestra en la terminal. Si cambias el texto del archivo, agregas un segundo párrafo o modificas el nombre del documento en la carpeta data, el resultado cambia en consecuencia. La prueba es útil porque confirma que el programa no inventa el contenido: lee exactamente lo que encuentra.

Ejercicio 5. Guardar una observación en un archivo nuevo

Leer archivos es útil, pero escribirlos lo es todavía más cuando quieres dejar constancia de un resultado o generar una nota breve automáticamente. Este ejercicio muestra cómo crear o reemplazar un archivo de texto desde Python.

Crea un archivo nuevo y copia este código:

from pathlib import Path

ruta_salida = Path(__file__).parent / "data" / "nota_generada.txt"
texto = "Se registro una observacion simple sobre el expediente EXP-010."

with open(ruta_salida, "w", encoding="utf-8") as archivo:
    archivo.write(texto)

print("Archivo guardado en:", ruta_salida)

Qué hace este código

El programa define una ruta de salida, prepara un texto y luego lo guarda en un archivo nuevo. Si el archivo ya existía, reemplaza su contenido por el texto actual.

Qué hace cada parte

  • ruta_salida = ... define dónde se guardará el archivo.
  • texto = ... contiene el mensaje que quieres escribir.
  • open(ruta_salida, "w", encoding="utf-8") abre el archivo en modo escritura.
  • El modo "w" crea el archivo si no existe o borra y reemplaza el contenido si ya existe.
  • archivo.write(texto) escribe el texto en el archivo.
  • print("Archivo guardado en:", ruta_salida) sirve para confirmar visualmente dónde quedó guardado el documento.

Qué verás en la terminal

Verás una salida similar a esta:

Archivo guardado en: data/nota_generada.txt

Lo importante aquí no es solo el mensaje de la terminal, sino el efecto que deja el script en la carpeta: se crea un archivo con el texto indicado. Cambiar el contenido de texto, volver a ejecutar el script y abrir el archivo generado permite comprobar esa relación directa entre código y documento. También puede modificarse el nombre del archivo de salida o añadir \n dentro del texto para escribir varias líneas en lugar de una sola.

Ejercicio 6. Leer registros desde un archivo CSV

Muchos datos del trabajo jurídico no están guardados en un solo bloque de texto, sino en tablas con columnas y filas. Un formato muy común para eso es el CSV. Este ejercicio muestra cómo leer un CSV básico y recorrer sus registros uno por uno.

Antes de ejecutar el script, crea un archivo llamado expedientes.csv dentro de tu carpeta data con este contenido:

codigo,estado,responsable
EXP-001,En revision,Ana Perez
EXP-002,Archivado,Luis Soto
EXP-003,Resuelto,Carla Ruiz

Luego crea un archivo nuevo y copia este código:

import csv
from pathlib import Path

ruta_csv = Path(__file__).parent / "data" / "expedientes.csv"

with open(ruta_csv, "r", encoding="utf-8") as archivo:
    lector = csv.DictReader(archivo)

    for fila in lector:
        print(
            fila["codigo"],
            "-",
            fila["estado"],
            "- responsable:",
            fila["responsable"],
        )

Qué hace este código

El programa abre un CSV, lo interpreta como una secuencia de filas con nombres de columna y luego imprime cada registro con una pequeña frase de salida.

Qué hace cada parte

  • import csv carga la biblioteca estándar de Python para trabajar con archivos CSV.
  • csv.DictReader(archivo) lee cada fila como un diccionario.
  • Eso significa que puedes acceder a cada dato usando el nombre de la columna, por ejemplo fila["codigo"].
  • for fila in lector: recorre una fila por vez.
  • El print(...) final arma una salida más legible combinando varios campos.
  • Se usa DictReader porque permite pensar cada fila como un pequeño registro con etiquetas claras, algo muy útil cuando trabajas con datos administrativos.

Qué verás en la terminal

EXP-001 - En revision - responsable: Ana Perez
EXP-002 - Archivado - responsable: Luis Soto
EXP-003 - Resuelto - responsable: Carla Ruiz

Cada línea aparece porque el bucle for toma una fila distinta del CSV y extrae tres campos: código, estado y responsable. Si agregas una nueva fila al archivo, cambias un estado o modificas el texto del print(), el programa refleja esas variaciones sin tocar la lógica principal. Esa relación entre una fuente de datos y una salida controlada es una de las bases del trabajo posterior con tablas.

Datos tabulares: empezar a pensar con pandas

Cuando las tablas crecen, leer fila por fila ya no siempre es la manera más cómoda de trabajar. Ahí aparece pandas, una biblioteca muy usada para manejar datos en forma de tabla. En esta parte del capítulo no se busca dominarla por completo, sino empezar a verla como una herramienta que permite observar, filtrar, contar y resumir información. Esa familiaridad con registros y tablas no es un desvío técnico: es una preparación útil para etapas posteriores de analítica legal, donde la información jurídica ya no se revisa solo caso por caso, sino también como conjunto estructurado (Ashley et al. 2021).

Ejercicio 7. Crear una tabla simple en memoria

Antes de leer archivos con pandas, conviene ver cómo se construye una tabla básica directamente desde Python. Este ejercicio introduce el objeto más importante de la biblioteca: el DataFrame.

Crea un archivo nuevo y copia este código:

import pandas as pd

datos = {
    "expediente": ["EXP-001", "EXP-002", "EXP-003"],
    "estado": ["En revision", "Archivado", "En revision"],
    "monto": [1500, 0, 800],
}

tabla = pd.DataFrame(datos)
print(tabla)

Qué hace este código

El programa construye un diccionario con tres columnas y luego lo convierte en una tabla de pandas, que finalmente se muestra en la terminal. Detrás de esta operación sencilla ya asoma una de las razones por las que Python se volvió tan importante para trabajar con datos: incluso ejercicios introductorios descansan sobre un ecosistema técnico amplio y maduro de bibliotecas interoperables (Pedregosa et al. 2011; Virtanen et al. 2020).

Qué hace cada parte

  • import pandas as pd importa la biblioteca pandas usando el alias pd, que es la convención más común.
  • datos = {...} crea una estructura donde cada clave será una columna.
  • pd.DataFrame(datos) convierte ese diccionario en una tabla.
  • tabla es un DataFrame, es decir, una estructura tabular con filas y columnas.
  • print(tabla) muestra la tabla completa.
  • Se usa DataFrame porque permite trabajar con datos de una forma muy similar a una hoja de cálculo, pero programable.

Qué verás en la terminal

Verás algo parecido a esto:

  expediente       estado  monto
0    EXP-001  En revision   1500
1    EXP-002   Archivado      0
2    EXP-003  En revision    800

La tabla aparece así porque pandas organiza automáticamente los datos en filas indexadas y columnas con nombre. Cambiar un monto, agregar una fila nueva o incorporar una columna adicional como responsable permite comprobar que un DataFrame no es solo una impresión ordenada: es una estructura sobre la que después se podrá filtrar, contar y resumir información.

Ejercicio 8. Filtrar solo los registros pendientes

Una de las operaciones más útiles sobre tablas consiste en quedarte solo con los registros que cumplen una condición. Este ejercicio muestra cómo filtrar una tabla para ver únicamente los expedientes o multas que siguen pendientes.

Antes de ejecutar este ejercicio, crea un archivo llamado multas.csv dentro de tu carpeta data con este contenido:

expediente,estado,monto
EXP-001,Pendiente,1200
EXP-002,Pagado,800
EXP-003,Pendiente,1500
EXP-004,Pagado,600

Luego crea un archivo nuevo y copia este código:

import pandas as pd
from pathlib import Path

ruta_csv = Path(__file__).parent / "data" / "multas.csv"
tabla = pd.read_csv(ruta_csv)

pendientes = tabla[tabla["estado"] == "Pendiente"]
print(pendientes)

Qué hace este código

El programa lee un CSV con pandas, construye una tabla y luego crea una versión filtrada que conserva solo las filas cuyo estado es "Pendiente".

Qué hace cada parte

  • pd.read_csv(ruta_csv) abre el archivo CSV y lo convierte en un DataFrame.
  • tabla["estado"] selecciona la columna estado.
  • tabla["estado"] == "Pendiente" produce una serie de valores verdaderos o falsos.
  • tabla[...] usa esa comparación como filtro para quedarse solo con las filas que cumplen la condición.
  • pendientes guarda la tabla filtrada.
  • Se usa este tipo de filtro porque muchas preguntas reales empiezan así: mostrar solo los casos abiertos, pendientes, observados o archivados.

Qué verás en la terminal

Verás una salida similar a esta:

  expediente     estado  monto
0    EXP-001  Pendiente   1200
2    EXP-003  Pendiente   1500

Aparecen solo dos filas porque son las únicas donde la columna estado contiene el valor "Pendiente". Cambiar un estado en el CSV, reemplazar "Pendiente" por "Pagado" en el filtro o añadir nuevas filas al archivo permite advertir que el resultado no depende del número total de registros, sino del criterio definido para seleccionar.

Ejercicio 9. Contar cuántos registros hay en cada estado

Filtrar sirve para mirar una parte de la tabla. Contar sirve para resumirla. Este ejercicio muestra cómo averiguar cuántas veces aparece cada categoría dentro de una columna.

Crea un archivo nuevo y copia este código:

import pandas as pd
from pathlib import Path

ruta_csv = Path(__file__).parent / "data" / "multas.csv"
tabla = pd.read_csv(ruta_csv)

conteo_estados = tabla["estado"].value_counts()
print(conteo_estados)

Qué hace este código

El programa vuelve a leer la tabla y luego cuenta cuántas veces aparece cada valor distinto dentro de la columna estado.

Qué hace cada parte

  • tabla["estado"] selecciona la columna que quieres resumir.
  • value_counts() cuenta la frecuencia de cada categoría.
  • El resultado ya no es una tabla completa como antes, sino una serie resumida.
  • print(conteo_estados) muestra ese resumen en la terminal.
  • Se usa esta operación porque muchas veces no interesa revisar expediente por expediente, sino obtener una visión rápida del conjunto.

Qué verás en la terminal

Verás algo parecido a esto:

estado
Pendiente    2
Pagado       2
Name: count, dtype: int64

Ese resultado aparece porque value_counts() agrupa automáticamente los valores repetidos y calcula su frecuencia. Según la versión de pandas, la última línea puede variar un poco, pero la idea central es la misma: obtener un resumen por categorías. Si agregas más filas al CSV o introduces un nuevo estado como Observado, el conteo se actualiza sin necesidad de cambiar la lógica del programa.

Ejercicio 10. Calcular un promedio de montos

Además de filtrar o contar, las tablas también permiten hacer operaciones numéricas simples. Este último ejercicio del capítulo muestra cómo obtener el promedio de una columna de montos.

Crea un archivo nuevo y copia este código:

import pandas as pd
from pathlib import Path

ruta_csv = Path(__file__).parent / "data" / "multas.csv"
tabla = pd.read_csv(ruta_csv)

promedio_monto = tabla["monto"].mean()
print("Promedio de multas:", promedio_monto)

Qué hace este código

El programa lee el mismo archivo CSV, selecciona la columna numérica monto y calcula su promedio.

Qué hace cada parte

  • tabla["monto"] selecciona la columna de valores numéricos.
  • mean() calcula la media aritmética de esa columna.
  • promedio_monto guarda el resultado.
  • print(...) muestra el promedio en la terminal.
  • Se usa esta operación porque muchas preguntas sobre datos no se responden leyendo fila por fila, sino resumiendo con indicadores simples.

Qué verás en la terminal

Promedio de multas: 1025.0

Ese valor aparece porque pandas suma los montos 1200, 800, 1500 y 600, y luego divide el total entre cuatro registros. Cambiar uno de los montos, añadir una nueva fila o probar con otra columna si amplías el CSV permite observar cómo una variación puntual puede modificar el indicador general.
