2. Primeros pasos con Python

2. Primeros pasos con Python

¿Por qué un estudiante de Derecho debería aprender Python?

Python es un lenguaje especialmente útil para empezar porque su sintaxis es clara y permite concentrarse en la lógica del problema. En este curso no lo estudiamos como un fin en sí mismo, sino como una herramienta para traducir instrucciones, criterios y reglas jurídicas en pasos ejecutables.

Para un jurista, esto tiene valor práctico inmediato. Muchas tareas del trabajo legal consisten en revisar información, clasificar documentos, calcular plazos, detectar patrones, verificar requisitos y producir reportes. Todas esas tareas pueden describirse como instrucciones. Y cuando una instrucción puede describirse con claridad, también puede empezar a automatizarse.

ImportantIdea central

Programar no significa dejar de pensar como jurista. Significa aprender a expresar una lógica de trabajo con más precisión.

Qué aprenderás en esta sesión

Al finalizar esta sesión, deberías poder:

  • ejecutar scripts sencillos desde una terminal o desde VS Code;
  • reconocer variables, tipos de datos, entradas y salidas;
  • escribir condicionales, bucles y funciones básicas;
  • relacionar código simple con tareas jurídicas reales;
  • dejar evidencia de trabajo en un repositorio.

Antes de empezar

Para trabajar con este capítulo necesitas:

  • Python instalado;
  • Git disponible;
  • una terminal;
  • VS Code o un editor equivalente.

Si todavía no tienes ese entorno listo, revisa la sección de Tutoriales del manual.

NoteRecomendación de trabajo

No intentes entender todo en una sola lectura. Ejecuta un archivo, cambia uno o dos valores, vuelve a ejecutarlo y observa qué cambió. La mejor pedagogía aquí no es memorizar, sino probar.

Cómo piensa Python en nivel básico

El primer contacto con Python debe centrarse en ideas simples:

  • una instrucción produce un resultado;
  • una variable guarda información;
  • una condición permite decidir;
  • un bucle repite una tarea;
  • una función encapsula lógica reutilizable.

Un ejemplo mínimo:

nombre = "Ana"
print(f"Hola, {nombre}")

Ese pequeño script ya deja ver varias cosas:

  • hay una variable llamada nombre;
  • esa variable guarda texto;
  • print() muestra un resultado;
  • el código tiene una sintaxis que debe respetarse.

Variables y tipos de datos

Una variable es un nombre que usamos para guardar un dato y reutilizarlo después. En derecho, esto se parece bastante a trabajar con información etiquetada: número de expediente, monto, fecha de notificación, estado de un trámite o nombre de una parte.

numero_expediente = "EXP-2026-001"
plazo_dias = 5
monto_multa = 1250.50
documento_firmado = True

print(numero_expediente)
print(plazo_dias)
print(monto_multa)
print(documento_firmado)

En este ejemplo aparecen cuatro tipos básicos:

  • str: texto;
  • int: número entero;
  • float: número decimal;
  • bool: verdadero o falso.
TipTraducción al mundo jurídico

Piensa en una variable como un casillero con etiqueta. El contenido puede cambiar, pero la función sigue siendo la misma: guardar información para trabajar con ella después.

Entradas y salidas

Un programa también puede pedir datos al usuario y mostrar resultados. Eso es útil cuando no queremos dejar todos los valores escritos desde el inicio.

nombre = input("Escribe tu nombre: ")
print("Hola,", nombre)

También podemos pedir un dato numérico:

dias_retraso = int(input("¿Cuántos días de retraso hubo? "))
multa_por_dia = 25
total = dias_retraso * multa_por_dia

print("Monto total:", total)

Lo importante aquí es notar que muchas veces input() devuelve texto, y por eso conviene convertir el valor al tipo que realmente queremos usar.

Condicionales: tomar decisiones

Una gran parte del trabajo jurídico consiste en decidir qué ocurre si se cumple o no cierta condición. Python permite representar eso con if, elif y else.

plazo_vencido = True

if plazo_vencido:
    print("Corresponde revisar consecuencias del vencimiento")
else:
    print("El plazo sigue vigente")

Podemos hacerlo un poco más interesante:

tiene_firma = True
tiene_dni = True
tiene_pago = False

if tiene_firma and tiene_dni and tiene_pago:
    print("Solicitud admisible")
else:
    print("Solicitud con observaciones")

Ese tipo de estructura ya se parece bastante a una regla jurídica sencilla.

Bucles: repetir tareas

Cuando necesitamos revisar varios elementos, los bucles resultan especialmente útiles.

expedientes = ["EXP-001", "EXP-002", "EXP-003"]

for expediente in expedientes:
    print("Revisar:", expediente)

Esto es valioso porque muchas tareas del trabajo legal no se hacen una sola vez, sino sobre varios registros: expedientes, contratos, resoluciones, escritos o correos.

También existe while, aunque conviene empezar con cautela:

contador = 0

while contador < 3:
    print("Iteracion:", contador)
    contador += 1

Funciones: reutilizar lógica

Una función permite agrupar instrucciones para reutilizarlas después. Esto es especialmente importante cuando un criterio o una operación se repite.

def calcular_multa(dias_retraso, monto_por_dia):
    return dias_retraso * monto_por_dia

resultado = calcular_multa(4, 25)
print("Multa:", resultado)

En vez de repetir la misma fórmula varias veces, la dejamos encapsulada y lista para usar.

NoteRegla práctica

Si una lógica empieza a repetirse, probablemente ya conviene convertirla en función.

Un ejemplo jurídico más completo

Imagina que quieres verificar si una solicitud cumple tres requisitos básicos:

  • tiene firma;
  • tiene documento de identidad;
  • tiene pago de tasa.

Podemos expresarlo así:

def evaluar_solicitud(tiene_firma, tiene_dni, tiene_pago):
    if tiene_firma and tiene_dni and tiene_pago:
        return "Solicitud admisible"
    return "Solicitud observada"

resultado = evaluar_solicitud(True, True, False)
print(resultado)

No estamos resolviendo todo el problema jurídico. Estamos modelando la parte repetible y verificable de la revisión preliminar.

¿Qué relación tiene esto con la práctica jurídica?

Muchas tareas legales consisten en:

  • clasificar información;
  • revisar requisitos;
  • calcular montos o plazos;
  • producir mensajes según un supuesto;
  • recorrer listas de casos o documentos.

La utilidad de Python no está en impresionar con código. Está en volver visible una lógica de trabajo que ya existe en la práctica profesional.

WarningImportante

Un script didáctico no reemplaza por sí solo el análisis jurídico. Sirve para estructurar la parte operativa y repetible del problema.

Práctica en editor

Abre tu repositorio del curso y crea o modifica un archivo de práctica. Haz, como mínimo, estas cuatro pruebas:

  1. define variables con información jurídica simple;
  2. crea una condición;
  3. recorre una lista;
  4. escribe una función breve.

Si quieres un punto de partida, puedes usar algo como esto:

numero_expediente = "EXP-001"
plazo_vencido = False
observaciones = ["falta firma", "falta anexo"]

def estado_expediente(plazo_vencido):
    if plazo_vencido:
        return "Revisar urgencia"
    return "Plazo vigente"

print(numero_expediente)
print(estado_expediente(plazo_vencido))

for observacion in observaciones:
    print("Observacion:", observacion)

Git y GitHub

Después de probar tu script, registra el avance en el repositorio:

git add .
git commit -m "Resuelve sesion 2 de primeros pasos con Python"
git push

PSET de la sesión

Resuelve un pequeño ejercicio en Python vinculado con una tarea jurídica simple. Por ejemplo:

  • calcular un plazo;
  • clasificar un expediente;
  • validar una condición básica;
  • producir un mensaje según un supuesto.

El PSET debe incluir:

  • un archivo .py claro y legible;
  • al menos un ejemplo de entrada y salida;
  • un README breve explicando qué hace el programa;
  • commits verificables en el repositorio.

Preguntas de repaso

  1. ¿Qué diferencia hay entre una variable y un valor?
  2. ¿Por qué conviene convertir algunos datos antes de usarlos?
  3. ¿Qué función cumple un if?
  4. ¿Qué problema resuelven los bucles?
  5. ¿Por qué una función puede mejorar la calidad del código?

Ideas clave

  • Python sirve para pensar problemas con más claridad;
  • empezar simple es una buena decisión pedagógica;
  • buena parte de la lógica jurídica puede expresarse como condiciones, listas y funciones;
  • el valor del código está en la lógica que hace visible.
